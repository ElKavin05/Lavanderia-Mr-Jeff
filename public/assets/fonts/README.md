# Tipografías locales

- `UbuntuSans-Variable.ttf`: tipografía de lectura del sitio.
- `CormorantGaramond-SemiBold.ttf` y `CormorantGaramond-MediumItalic.ttf`: tipografía editorial para títulos.

Cormorant Garamond se distribuye mediante Google Fonts bajo la licencia SIL Open Font License 1.1. Fuente: <https://fonts.google.com/specimen/Cormorant+Garamond>.
