## Directrices de uso

1. Los recursos publicados en la cuenta oficial prueban la identidad visual, pero no equivalen automáticamente a un paquete de activos aptos para web.
2. Las piezas recientes detectadas están tratadas como composiciones promocionales; varias se identifican como contenido de IA. No deben convertirse en fondos, ni recortarse, ni imitarse literalmente.
3. El logo definitivo ya fue entregado por el cliente como PNG de alta resolución. Usar este archivo antes que cualquier avatar o captura de redes; un SVG seguiría siendo útil para escalado futuro, pero no bloquea la landing.
4. Los bodegones generados no deben presentarse como evidencia del local, personal, proceso o resultados de Mr Jeff. Su función es orientativa; pueden reemplazarse por fotografías originales cuando el cliente las entregue.
5. La dirección preparada para posteriores activos sociales es `public/assets/brand/social/`. Contiene únicamente un marcador de versión y está lista para archivos proporcionados o autorizados.

## Activos recomendados para solicitar

- Variante SVG o PNG transparente del logotipo, si está disponible, para optimizar su uso sobre fondos no blancos.
- Fotografía horizontal del local o del proceso de recepción.
- Dos a cuatro fotografías propias de prendas, empaques, equipo y/o delivery.
- Captura o archivo autorizado de la lista de precios 2026.
- Confirmación escrita de si Washday Hub debe aparecer o no en la nueva landing.
